# M1-M4 分析师模块（逆向自 tradingagents/agents/analysts/）

四份报告**相互独立、可并行**；每份报告只写自己的域，不做交易判断（"另一个 agent 决定交易"）。数据一律来自 `akshare_data.py` 输出，禁止编造。每份报告末尾附 Markdown 要点表。

---

## M1 市场技术分析（对应 market_analyst.py）

从下列指标中**选 ≤8 个互补指标**（避免冗余，如不同时选 RSI 与 KDJ 的同类动量），说明选择理由，然后基于 `akshare_data.py indicators` 的输出写详细趋势报告：

- 趋势：`ma50`（50日中期趋势/动态支撑阻力）、`ma200`（200日长期基准/金叉死叉）、`ema10`（短期动量）
- 动量：`macd` / `macd_signal` / `macd_hist`（交叉与背离）
- `rsi14`（70/30 超买超卖；强趋势中长期钝化，须结合趋势判断）
- 布林：`boll_mid` / `boll_upper` / `boll_lower`（突破与回归；强趋势中价格可沿轨运行）
- 波动：`atr14`（止损与仓位设定依据）
- 量能：`vwma20`（量价配合确认趋势）

硬规则：
- 先看 `snapshot`（实时快照）作为一切精确价格声明的唯一事实来源；其他数据与快照冲突时**标注差异**，不得编造调和数字
- 不得声称历史回踩支撑成功、精确涨跌幅，除非数据中有具体日期与价格支撑
- 输出：趋势判断（上涨/下跌/震荡）、关键支撑/阻力位（绝对价格）、量价特征、可操作要点

## M2 基本面分析（对应 fundamentals_analyst.py）

基于 `akshare_data.py fundamentals` 的财务摘要（ROE/毛利率/净利率/资产负债率/营收与净利增速等），写公司基本面综合报告：
1. 财务质量：盈利能力（ROE 趋势）、成长性（营收/净利增速）、偿债与现金流风险
2. 估值：当前 PE/PB（来自 snapshot）对比自身历史分位与行业水平的定性判断
3. 股东与筹码：如有股东户数/大股东变动数据则纳入
4. 每个关键数字标注报告期；缺失项声明缺失

## M3 新闻宏观分析（对应 news_analyst.py）

基于 `akshare_data.py news` 的个股新闻列表（默认近 20 条）写「与交易相关的世界状态」报告：
1. 个股事件：公告、业绩、订单、监管、行业政策（逐条给出日期与标题来源）
2. 宏观背景：货币政策、行业景气、相关大宗/汇率（可用常识框架，但涉及数字须来自数据）
3. 前瞻事件：未来 1-3 个月可能的催化剂/风险点
4. 区分事实与推测；标题即来源，禁止虚构新闻

## M4 市场情绪分析（对应 sentiment_analyst.py，结构化输出）

输入：新闻标题情绪 + 龙虎榜/资金流数据（如可得）。输出**固定结构**：

```
**Overall Sentiment:** **{六档之一}** (Score: {0-10 一位小数}/10)
**Confidence:** {low|medium|high}
{叙述：①分来源证据（引用条数/占比/代表性内容）②来源间分歧与一致 ③主导叙事 ④催化剂与风险 ⑤要点表格}
```

- 六档：Bullish / Mildly Bullish / Neutral / Mixed / Mildly Bearish / Bearish
- 分数锚点：Bullish≈6.5-10，Mildly Bullish≈5.5-6.4，Neutral/Mixed≈4.5-5.5，Mildly Bearish≈3.5-4.4，Bearish≈0-3.4
- 置信度：数据点 <5 或来源缺失 → low；有数据但稀疏 → medium；多来源充分 → high
- Mixed 用于来源方向明确对立；Neutral 仅当所有来源真沉默
